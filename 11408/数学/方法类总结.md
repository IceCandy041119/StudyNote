# 方法类总结（跨章节通用方法）

> 把散落在各章、可跨题型复用的「方法论」集中在此，供数学各科笔记（高数 / 线代 / 概率）共用，遇到新方法随时补充。

## 区间再现

**原理**：作区间中点对称的换元 $x=a+b-t$，定积分 $I=\int_a^b f(x)dx$ 被改写成另一种形式的自身（区间不变），与原式相加（或相减）消掉难积部分。

- **一般式**：$\int_a^b f(x)\,dx=\int_a^b f(a+b-x)\,dx$。
- **特例 1（消 $x$）**：$\int_0^\pi x f(\sin x)\,dx=\frac\pi2\int_0^\pi f(\sin x)\,dx$（$x=\pi-t$）——把乘在 $\sin$ 函数上的因子 $x$ 化成常数。
- **特例 2（sin/cos 互换）**：$\int_0^{\frac\pi2}f(\sin x,\cos x)\,dx=\int_0^{\frac\pi2}f(\cos x,\sin x)\,dx$（$x=\frac\pi2-t$）——被积函数中 $\sin,\cos$ 互换后积分不变。

**适用场景**：

1. 被积函数含 $x$ 与 $\sin x,\cos x$ 混乘、直接积不动 → 换元把 $x$ 化掉；
2. 被积函数 $\sin,\cos$ 互换后结构不变 → 互换后与原式**相加**化简（如 $I+J=\int 1\,dx$）；
3. 换元后得到 $I=$ 自身（或其线性组合）→ 解方程求出 $I$。

**例题**：[高数辅导讲义 P123 例8](../题库/数学/错题/高数辅导讲义-P123-例8-2026-09-08.md)（$\int_0^{\frac\pi2}\frac{\sin x}{\sin x+\cos x}dx$，方法二）。

## 数学归纳法

**适用**：证明与正整数 $n$ 有关的命题。

- **第一类（普通归纳法）**：① 验证起始值（$n=1$，也可能是 2 等）成立；② 假设 $n=k$ 成立，推出 $n=k+1$ 成立；③ 由归纳原理，命题对一切 $n\ge$ 起始值成立。
- **第二类（强归纳法）**：① 验证起始值成立；② 假设 $n\le k$（即 $n=1,2,\cdots,k$）**全部**成立，推出 $n=k+1$ 成立。当证明 $n=k+1$ 需要用到**多个前项**（而不仅是 $k$ 一项）时用第二类，如递推式 $a_{n+1}=a_n+a_{n-1}$ 型（斐波那契型）。

**典型用途（高数为例）**：

1. 证明递推数列的**有界性**（先猜界 $M$，再验证 $x_1\le M$ 且 $x_k\le M\Rightarrow x_{k+1}\le M$）——见 [[高等数学#数列极限的常见题型与方法|1.2 数列极限]]；
2. 证明 **$n$ 阶导数公式**（如 $(\sin x)^{(n)}=\sin(x+\frac{n\pi}{2})$）；
3. 证明**积分递推关系**（$I_n$ 与 $I_{n-1}$ 的等式，如华里士公式即可用归纳法证）；
4. 与 $n$ 有关的**不等式**（数列、函数、积分不等式）。

**注意**：先「猜」出结论再归纳证明；起始值不一定是 1；递推式依赖前两项及以上时优先考虑第二类。
