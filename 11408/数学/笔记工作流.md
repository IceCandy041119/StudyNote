# 数学笔记工作流（v1）

> 本文档固化当前数学笔记体系的结构、标准流水线与格式约定，并列出已知差距与改进方向。改动体系时先更新本文档。

## 一、笔记体系全景（三层结构 + 题目联动）

```
数学/

│   ├── 第一章 函数 极限 连续.md
│   ├── 第二章 一元函数微分学.md
│   └── 第三章 一元函数积分学.md
├── 线代辅导讲义/                  # 第一层：主笔记
│   ├── 第一章 行列式.md
│   └── 第二章 矩阵.md
├── 高等数学.md                    # 第二层：补充笔记（讲义未覆盖的深度技巧/反例/辨析）
├── 线性代数.md                    # 第二层：补充笔记
├── 概率论与数理统计.md            # 概率笔记（暂未接入本流水线）
├── 方法类总结.md                  # 第三层：跨章节通用方法论（区间再现、归纳法等）

```

**三层分工**：

| 层 | 文件 | 记什么 |
|---|---|---|
| 主笔记 | `高数辅导讲义/`、`线代辅导讲义/` | 讲义知识点：定义、定理、性质、公式、方法总结（**不含例题**） |
| 补充 | `高等数学.md`、`线性代数.md` | 讲义没有或更深的：反例、推导、辨析、易错点、一题多解技巧 |
| 方法 | `方法类总结.md` | 跨章节、跨科目可复用的方法论（按「原理/特例/适用场景/例题链接」组织） |

**联动关系**：主笔记 --📌 补充锚点--> 补充笔记；方法类总结 <--链接-- 题库错题；错题 --知识点链接--> 主笔记对应小节。

## 二、标准流水线（整理新章节的五步）

### 第 1 步：定范围
- 扫描版 PDF（无文本层）先 OCR 目录页确定各章**书页**范围；页码换算：**书页 = PDF 页 + 偏移**（本次两本讲义偏移均为 −13）。
- 目录页可用 `pdftoppm -f 1 -l 12 -r 120 -png` 渲染后交给 extract.py 识别。

### 第 2 步：提取（OCR）
```bash
python3 ~/.pi/agent/skills/literature-summarizer/scripts/extract.py \
  'pdf/<讲义>.pdf' --pages '16-31' --page-offset -13 --dpi 150 -o '数学/.extract/<段>.txt'
```
- 输出为逐页标记文本【第 N 页 / 共 M 页】（N = 书页）。
- **并行化**：按每段 ≤20 页切分，多个 subagent lane 并行跑 extract.py；每 lane 只写自己的文件。
- 约定 dpi 150（公式可读性够，成本较低）；重点页可 200。

### 第 3 步：整理（讲义主笔记）
- 每章一个 subagent（fresh 上下文），读对应 .extract 文本，产出该章 `.md`。
- 硬性要求：**剔除全部例题/解析/习题**；保留「方法总结」「注/评注」中的知识性结论；LaTeX 用 `$...$`/`$$...$$`；结构按原书章节层级；开头写来源行：
  ```
  # 第X章 <标题>
  > 来源：《<书名>》第X章
  > 补充材料：…见 [补充笔记](<../高等数学.md>)   ← 合并时再加
  ```

### 第 4 步：去重合并（主/补双轨）
- 把旧笔记（如严选题整理）与新讲义笔记**逐节比对**：
  - 讲义已完整覆盖 → 从旧笔记删除；
  - 旧笔记有增量（反例/推导/辨析/技巧）→ 保留增量、重组为「补充笔记」；
  - 补充笔记章节按讲义章节对齐，标题唯一（锚点需要）。
- 主笔记相应位置加引用块：
  ```markdown
  > 📌 补充：本节在严选题笔记中有讲义未收录的技巧/反例，详见：[<小节标题>](<../高等数学.md#<小节标题>)。
  ```
- 分两阶段并行：先「去重重组」writer（每文件一个），再「加锚点」writer（每主笔记一个），锚点标题从重组后文件 `grep '^#'` 原样复制。

### 第 5 步：校验（必做清单）
- [ ] 锚点全部命中：`](<../X.md#标题>)` 与补充笔记标题逐一比对（脚本见下）；
- [ ] 标题无同名重复（Obsidian 锚点唯一性）；
- [ ] LaTeX 配平（每行 `$` 个数为偶、`$$` 总数为偶）；
- [ ] 可疑公式回原页复查（渲染原页再 OCR，必要时求导/代入验证）；本批次曾修正：∫dx/(1+x⁴) 结论误录、⊂/⊃ 图形乱码、「数学三要求」标注颠倒；
- [ ] 数一/二/三考纲标注核对（本项目为数一：参数方程求导数三不要求、经济学应用数学二专属等）。

校验脚本（可直接复用）：
```bash
cd 数学 && python3 - << 'EOF'
import re, glob, collections
pat = re.compile(r'\]\(<\.\./([^>]+?)\.md#([^>]+?)>\)')
anchors = [(f,m.group(1),m.group(2)) for f in glob.glob('*辅导讲义/*.md')
           for m in pat.finditer(open(f,encoding='utf-8').read())]
def headings(p):
    return [re.sub(r'^#{1,4} ','',l.strip()) for l in open(p,encoding='utf-8')
            if re.match(r'^#{1,4} ',l.strip())]
gh,xh = headings('高等数学.md'), headings('线性代数.md')
miss = [(f,t,a) for f,t,a in anchors if a not in (gh if t=='高等数学' else xh)]
print('anchors:',len(anchors),'missing:',miss)
for n,h in [('高等数学.md',gh),('线性代数.md',xh)]:
    d=[k for k,v in collections.Counter(h).items() if v>1]
    print(n,'重复标题:',d)
EOF
```

## 三、格式约定

1. **LaTeX**：行内 `$...$`、独立 `$$...$$`；禁止 `\(...\)`（Obsidian 兼容）。
2. **考纲标注**：涉及数一/二/三差异处显式标注（本项目按数学一）。
3. **标题唯一**：同文件内小节标题不重名，否则锚点失效。
4. **来源可追溯**：主笔记开头保留「> 来源：《书名》第X章」；补充笔记开头保留与主笔记的对应关系。
5. **.extract 管理**：OCR 原文是临时产物，章节整理+校验完成后应归档（如 `.archive/`）或删除，不长期占用 vault（当前 588K）。
6. **新增跨章节方法**：遇到可复用方法论（辅助函数构造、K 值法、区间再现、分部积分选 uv、夹逼…）时，在 `方法类总结.md` 按「原理/特例/适用场景/例题链接」补一条，并链接回主笔记。

## 五、执行模板（下次整理时复制）
