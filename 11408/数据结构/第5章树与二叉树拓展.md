## 拓展1 二叉树的遍历与栈序列

**对应笔记**：5.3 二叉树的遍历和线索二叉树。

-  **二叉树先序遍历和中序遍历的关系相当于以先序序列作为入栈次序，以中序序列作为出栈次序**
	- 考虑先序和中序遍历算法的非递归实现
		- 可以发现先序遍历和中序遍历的栈序相同，且先序遍历是在节点第一次访问时（压栈）记录，而中序遍历是在节点第二次访问时（弹出）记录。故先序遍历和中序遍历的关系相当于以先序序列作为入栈次序，以中序序列作为出栈次序。
			- 这个也说明了，通过先序和中序遍历序列可以还原出一个确定的二叉树。
		- 而后序遍历对于有右孩子的节点会再次入栈，并不记录，故会造成序列的混乱，如下方第三个例子，如果把后序遍历的树当作出栈序列，由于再次入栈，会造成不同结构的树出现相同的出栈序列。由此可以推出，仅有先序和后序遍历序列无法还原出一个确定的二叉树。
	- 另一种思路：
		- 对于一颗二叉树，先序序列为\[根、左子树、右子树]，可以假定先序序列构成的入栈顺序为\[1,2,3,...,n],对于该序列，一定存在一个**k**，为最左端的叶子节点，此时会将这个点出栈,得到出栈序列\[k],由k分割的\[1,2,3,...,k-1]为**k**代表节点的祖先节点，接下来的入栈和出栈代表了**k**节点的右子树，直到出栈操作出现**k-1**，同理处理**k-1**的右子树，以此类推，直到所有元素出栈，处理完**1**的右子树后，整个树确定下来。
		- 或者说，由于中序序列为\[左子树、根、右子树]组成，根可以起到分隔左子树与右子树有多少个点，从而得到中序序列的组合可以有$\sum_{i=1}^{n}(f(n-k) * f(k-1))，f(0)=1, f(1)=1$种,即$\frac{1}{n+1}C^{n}_{2n}$种。相当于以先序序列为入栈序列，以中序序列为出栈序列。
			- 可以说，因为先序序列可以产生$\frac{1}{n+1}C^{n}_{2n}$种中序序列，故可以确定$\frac{1}{n+1}C^{n}_{2n}$个二叉树，根据中序调用函数的性质，相当于有$\frac{1}{n+1}C^{n}_{2n}$种出栈方式。
				- 因为中序调用函数对于一颗二叉树而言，中序调用函数先入栈根节点，不访问，再递归调用进入左子树，如果为空出栈，并记录，然后出栈根节点，然后递归调用进入右子树。
					- 跟第一种描述差不多。相当于说，递归就是入栈，第二次返回时就为出栈了。
						- 前序和中序分别在记录之前仅调用过0次和1次递归函数，故可以对应入栈出栈，因为接下来的调用相当于另立山头，不会影响。
						- 但后序在记录前会调用两次递归函数，因此对于一个节点来说，第一压入栈中，即执行在函数时，在第一次调用递归函数前，记为压栈，在第一次调用递归函数结束后，记为弹出，在第二次调用递归函数前，又压入栈中，结束后才彻底弹出，如果将这个当作出栈序列会造成了构成的树不确定性，可能使不同结构的树有着相同前序与后序序列。

typedef struct BTree{
	int id;
	struct BTree* leftp;
	struct BTree* rightp;
}BTree;

// warning：代码未经测试，仅做思路参考

void pre_order(BTree *root){ // 先序遍历
	if(!root) return;
	BTree* stack[20];
	int stackp = -1;
	BTree* p = root;
	while(p || stackp != -1){
		while(p){
			printf("%d", p->id);
			stack[++stackp] = p;
			p = p->leftp;
		}
		if(stackp != -1){
			p = stack[stackp--];
			p = p->rightp;
		}
	}
}

void in_order(BTree *root){ // 中序遍历
	if(!root) return;
	BTree* stack[20];
	int stackp = -1;
	BTree* p = root;
	while(p || stackp != -1){
		while(p){
			stack[++stackp] = p;
			p = p->leftp;
		}
		if(stackp != -1){
			p = stack[stackp--];
			printf("%d", p->id);
			p = p->rightp;
		}
	}
}

void post_order(BTree *root){ // 后序遍历
	if(!root) return;
	BTree* stack[20];
	int stackp = -1;
	BTree* p = root;
	BTree* handled_Right_Node = null;
	while(p || stackp != -1){
		while(p){
			stack[++stackp] = p;
			p = p->leftp;
		}
		if(stackp != -1){ //如果p到达了最左边的节点的空左孩子节点
			BTree* temp = stack[stackp--]; //取该父节点
			if(temp->rightp == null || handled_Right_Node == temp->rightp){ 
				// 如果也没有右孩子则为后序遍历的第一个输出
				printf("%d", temp->id);
				// 后续的话，因为最顶层的循环，会找到该叶节点的父节点，如果该节点为右孩子
				// 不处理该右孩子的父节点的右指针判断会导致不断循环处理该父节点和右孩子节点
				handled_Right_Node = temp;
				// 这样，记录了刚处理过的右孩子节点，故其父节点因为处理完了左右子树，也会
				// 被处理
			}else{ // 如果有右孩子，处理该节点的右子树
				stack[++stackp] = temp; // 将该父节点放回去
				p = temp->rightp; // 处理右子树
			}
		}
	}
}
