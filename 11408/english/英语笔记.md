
## 状语从句：副词性从句，补充说明，充当状语

副词adv.的位置很自由，句首，句中，句末都可以放

关系连词 + 分句，主谓宾
主谓宾，关系连词 + 分句

故以上两种形式的从句，表达的意思是一样的，关系连词 + 分句都用于补充说明修饰**谓语**。

当分句主语和主句主语一样的时候，可以省略分句的主语，如果分句的主语有be，be动词也可以省略。

关系连词：

- though
- although
- if
- when
- why
- where

## 非谓语

英语的句子一般是**主谓宾**。

有了谓语的情况下，还有其他的动词，一般用于补充谓语的动作。

**没有加逗号的非谓语动词**，一般情况下，用来修饰前面的名词。

instance：
- I like to use computers having some software。 我喜欢有软件的计算机。
- I like to use computers bought by my dad。 我喜欢我爸买的计算机。

**有逗号**，不一定用来修饰前面的名词，也可能修饰前面整个句子，还可能形容前面的名词。

instance：
- I like to doing exercises，making me happy。我喜欢锻炼，这件事使我快乐。
- I like to read books，writing some notes。我喜欢读书，并做一些笔记。
- I like to use computers，bought by my dad。

writing some notes，I like to read books。这个框架可能是非谓语动词。

## 定语从句 adj.

修饰名词

I have an apple that/which is red. 我有个红苹果。

**限定性定语从句**，没有逗号，限定死了，只用于修饰前面的名词。

instance:
- I have a computer whose software is good.
- I like this book (that) you read.
	- 省略关系代词:当先行词在定语从句中做宾语的时候，关系代词可以省略。

**非限定定语从句**，有逗号，只能用which，不一定用于形容前面的名词

instance:
- I like to read books,which is useful for me.
	- which代指我喜欢读书这件事
- I like to read books,which are expensive
	- which代指这些书

**带介词定语从句**

instance:
- I like this table on which there is a book
	- 把介词on放在which前面而不是句末，翻译的时候更加顺畅一些，我喜欢这个桌子，（在桌子（which）上面（on））是一本书
- I like this book through which I can learn many things.


>[!note] 定语从句和状语从句的区别
>where when
>- I like this school where I can learn many things.
>	- 如果where修饰学校，表示我喜欢这个学校，在这里我可以学到很多东西
>	- 如果where修饰like，表示我喜欢可以学到很多东西的学校
>	- 具体通过语义去判断
>- I like this week when I am happy.
>	- 我喜欢这周，这周我很快乐
>	- 我在高兴的时候喜欢这周

## So that / Such that

相当于如此以至于
so that    连词
句子1 so that 句子2
- 句子1发生了，有了句子2
	- 否则不要用so that

So adj./adv. that 完整的句子
- adj.的话如果前面的有宾语则是形容宾语
	- 比如说
		- I play the game so smart that..
			-  我玩这个聪明的游戏以至于
	- 如果是I am
		- I am so smart that...
			- 我很聪明以至于
- 故应正确区分副词和形容词
	- I play the game so smartly that
		- 我玩这个游戏玩的很聪明以至于
- 要与前面的句子说的通

Such +n. that 完整的句子
- 同样的，要与前面的句子说的通
- You are such a good boy that you can do this.
