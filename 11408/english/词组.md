## 一、语法·用法笔记

- **as ... as**：同级比较。两个 as 之间是原级形容词/副词，第二个 as 理解为"正如、和……一样"；`as + 倍数词 + as` 表"A 是 B 的几倍"（如 twice as much as）。
- **as well as**：① 相当于 and，连接并列成分（更强调前者）；② 也可看作 as...as 结构（as well as he does）。
- **as long as**：作连词"只要"；不引导句子时如同 as...as。
- **since**：介词/连词"自从 + 时间"；连词/介词"因为"（连词 ≈ because 后接句子，介词 ≈ because of 后接名词）。
- **for**：介词"为了"；连词 ≈ because。
- **however**：句中作副词"但是"；`However + adj./adv.` 表"无论多么"（让步）。
- **yet**：句首 ≈ but；肯定句/否定句中"至今还没"（表"尚未"）。
- **but**：连词"但是"；介词"除了"（anything but 绝非、no one but you 除了你没人）；副词"仅仅、只是"（is but all too natural 不过是太自然不过了；She is but a child. 她只是个孩子）。判断口诀：but 后跟名词/形容词短语、能换成 only，就是副词"不过"。
- **rather than**：宁愿、而不是；rather ≈ very。
- **instead of doing/n, 主句**：不做……而做……。
- **by doing sth, 主句**：通过做某事。
- **with + n. + doing/done/介词短语**：with 复合结构，表伴随/原因/方式（doing 主动、done 被动）。
- **combined with A, 主句**：加上 A 后，主语……。
- **时间概念词引导完整主句**：every time / the day / one hour after / the moment 等可作连词引导时间状语从句。
- **those/these** 后面没有其他词，一般默认为"人"。
- **used to do** 过去常常；**be/get used to doing** 习惯于；**be used to do** 被用来。
- **a number of** + 复数谓语"许多"；**the number of** + 单数谓语"……的数量"。
- **give sb sth / give sth to sb**；**offer sb sth**；**call/term A B**（把 A 称为 B）。
- **leave A(n.) + B(adj./n./介词短语)**：使 A 处于 B 状态（leave = make）。
- **sb risk doing sth**：冒风险做某事。
- **not so much A as B**：与其说是 A，不如说是 B。
- **A is more of a B than a C**：A 更像是 B 而不是 C。
- **It appears/seems that...** 似乎……；**It does not appear that...** 似乎不……。
- **It occurs to sb that...** 某人突然想到……。
- **as + 省略（方式状语从句）**：I have discovered this truth, as Tom will (discover it) after sth. —— as 引导方式从句，省略与主句相同的谓语和宾语，翻译时补出。
- **系动词**：become / seem / look / taste / smell / feel / sound + 形容词。
- **among 倒装句**：介词短语提前引起完全倒装，理解时先还原语序（… are among many students in school）。
- **be busy doing sth** 忙于做某事；**keep doing** 持续做。
- **would/could/should have done**（虚拟语气）：本来会 / 本来可能 / 本来应该。
- **in the world**（用于疑问词后）：到底、究竟。
- **The difference between A and B**：A 与 B 在意义上需并列；也可接复数（the difference between these apples）。
- **way**：可单独作状语（the way you play）或作主语（your way that...）。
- **after/before**：介词 + 名词；连词 + 句子。
- **allow sb to do sth**；**allow for sth**（考虑到、顾及）；一般不用 allow sth。
- **think that + 从句**；**think of/about + 名词**（一般不直接 think + 名词）。
- **charge / cost / spend**：商家 charge 消费者；商品 cost sb + 钱；sb spend + 钱 on sth。
- **some/about + 时间** ≈ 大约；**about + 数字** ≈ 大约。
- **单数时间/金钱/距离作主语视为单数**（Ten dollars is enough）。
- **one / the other / another / others / the others**：两者之间用 `one ... the other`（一个……另一个）；三者及以上用 `one ... another`（一个……另一个，another 指"三者以上的任意一个"）。复数中 `some ... the others` 指"一些……其余的（全部剩余）"，`some ... others` 指"一些……另一些（不强调剩余）"。
- **each other / one another（相互代词）**：传统规则 each other 用于两者之间、one another 用于三者及以上之间；现代英语中两者基本可互换（考试按传统规则作答更稳妥）。
- **A is to B as/what C is to D**：A 之于 B，正如 C 之于 D（类比句型）。is to = 之于（表两者关系，后面跟名词）；区别于 be to do（将要做/应当做，后面跟动词原形）。例：Smile is to face as sunshine is to flower. 微笑之于脸庞，正如阳光之于花朵。

#### 可积累的写作/翻译表达
| 表达 | 词性 | 释义 |
|------|------|------|
| In spite of ..., ... | sentence pattern | 尽管……，……（介词短语表让步）|
| neither ... nor ... | sentence pattern | 既不……也不…… |
| not ... but ... | sentence pattern | 不是……而是…… |
| adj. + enough + to do | sentence pattern | 足够……以至于能…… |
| higher than + 名词短语 | sentence pattern | 高于……（省略式比较）|
| than + 倒装从句（than do ...）| sentence pattern | 比……（比较对象较长时助动词提前）|
| Hence + 名词短语 | sentence pattern | 因此有了……（无谓语名词句，承上启下）|
| Indeed. | sentence pattern | 确实如此。（承前省略的回答句）|
